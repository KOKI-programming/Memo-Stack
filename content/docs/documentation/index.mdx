Memo Stuck は、メモや To-Do リスト、プログラムコードなどを簡単に保存できる Web アプリケーションです。このマニュアルでは、Memo Stuck の使い方を随時ガイドします。

## 特徴

Memo Stuck は次のような特徴を揃えています。

1. **メモ数無制限**: メモを無制限に保存できます。
2. **無料で利用可能**: 使用料金なしでサービスを機能的に利用できます。
3. **簡単ログイン**: メールアドレスやソーシャルログインを提供。
4. **簡単操作**: 誰でも容易に操作可能なユーザーインターフェイス。
5. **To-Do リストの作成**: 日常的な任務を簡単に管理できます。
6. **プログラムコードの保存**: コードを添付したメモ保存に対応。

## Memo Stuck の構築について

Memo Stuck の構築は、下記のツールを用いています。

- **[ContentLayer](https://contentlayer.dev)**: MDX ファイルを管理し、コンテンツを変換します。
- **[MDX](https://mdxjs.com)**: React コンポーネントを Markdown で書けるようにします。
