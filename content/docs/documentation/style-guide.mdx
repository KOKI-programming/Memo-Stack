# Memo Stack スタイルガイド

Memo Stack では、メモの整理やタスク管理をシンプルかつ効果的に行えます。このスタイルガイドは、Memo Stack で使用できる要素やフォーマットについて詳しく説明します。これを活用して、メモやコードをよりわかりやすく整理しましょう。

---

## 見出し

Markdown 形式では、見出しを`#`を使って作成します。以下は見出しの階層の例です：

# 見出し 1 (h1)

## 見出し 2 (h2)

### 見出し 3 (h3)

#### 見出し 4 (h4)

##### 見出し 5 (h5)

###### 見出し 6 (h6)

---

## テキストスタイル

テキストの強調や装飾をする方法をご紹介します：

- **太字**: `**太字**` → **太字**
- _斜体_: `_斜体_` → _斜体_
- ~~取り消し線~~: `~~取り消し線~~` → ~~取り消し線~~
- **_太字と斜体の組み合わせ_**: `**_太字と斜体の組み合わせ_**` → **_太字と斜体の組み合わせ_**

---

## リスト

### 箇条書きリスト

以下は箇条書きリストの例です：

- 第一項目
  - ネストされた項目 1
  - ネストされた項目 2
- 第二項目
- 第三項目

### 番号付きリスト

以下は番号付きリストの例です：

1. 最初の項目
2. 次の項目
   1. サブ項目 1
   2. サブ項目 2
3. 最後の項目

---

## 引用

引用は、他の情報や強調したい内容を目立たせるのに便利です：

> これは引用の例です。  
> Markdown では`>`を使用して作成します。

---

## コードブロック

プログラムコードやコマンドをわかりやすく表示する方法です。

### インラインコード

単語や短いコードを強調したいときに使用します：  
例: `console.log("Hello, World!");`

### コードブロック

複数行のコードをフォーマットする方法です：

```javascript
// JavaScriptの例
function greet(name) {
  console.log(`こんにちは、${name}さん！`);
}

greet("ユーザー");
```
