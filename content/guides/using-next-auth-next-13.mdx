---

## Post Writer とは？

Post Writer は、次のような特徴を持つ記事作成・管理ツールです：

- **簡単な記事作成**: Markdown 記法を活用して、美しい記事を簡単に作成。
- **プレビュー機能**: 公開前に記事の見た目を確認。
- **整理された管理機能**: 投稿をカテゴリやタグで整理し、後から簡単に見つけることが可能。
- **モダンな UI**: ユーザーフレンドリーなデザインで効率的に作業。

## 始める前に必要な準備

### 1. アカウントの作成

初めてご利用の場合は、アカウントを作成してください。

1. [サインアップページ](https://example.com/signup)にアクセスします。
2. 必要事項（メールアドレス、パスワードなど）を入力します。
3. 「登録」ボタンをクリックし、登録を完了します。
4. 登録後、メール認証が必要な場合は、届いたメールを確認して認証リンクをクリックしてください。

## Post Writer の基本操作

### 1. ダッシュボードへのログイン

1. [ログインページ](https://example.com/login)にアクセスします。
2. 登録時のメールアドレスとパスワードを入力してログインします。
3. ダッシュボードが表示され、すべての機能にアクセス可能になります。

---

### 2. 新しい投稿を作成

1. **ダッシュボード画面**から「新しい投稿を作成」ボタンをクリックします。
2. 記事作成画面が開きますので、以下を入力します：
   - **タイトル**: 記事のタイトルを入力します。
   - **本文**: Markdown 形式で記事の内容を記述します。

#### Markdown 記法の基本例：

```markdown
# サンプル投稿タイトル

ここに本文を入力します。

## セクションタイトル

- 箇条書き項目 1
- 箇条書き項目 2

**太字**や*斜体*も簡単に作成できます。
```

3. 必要に応じて、カテゴリやタグを追加して記事を整理します。
4. 「プレビュー」ボタンをクリックして、記事の見た目を確認します。
5. 問題がなければ「公開」ボタンをクリックして記事を公開します。

---

### 3. 投稿を管理

ダッシュボードでは、作成した投稿の一覧を確認できます：

- **編集**: 記事の内容を更新する場合、投稿をクリックして編集画面を開きます。
- **削除**: 不要な投稿は削除可能です。
- **公開状態の切り替え**: 公開/非公開の設定を簡単に変更できます。

## より便利に使うためのヒント

### プレビュー機能を活用する

- 記事を公開する前に、プレビューでフォーマットやスタイルを確認してください。
- 特にコードブロックや画像の表示を確認するのがおすすめです。

### カテゴリとタグを整理する

- 記事にカテゴリやタグを設定すると、後から検索しやすくなります。
- 一目で関連する記事を見つけられるよう、整理しておくと便利です。

## よくある質問とトラブルシューティング

### Q. Markdown 記法がわかりません

Markdown は簡単な記法で文章を構成できます。以下は主要な記法の例です：

- **見出し**: `# 見出し1`、`## 見出し2`
- **リンク**: `[リンクテキスト](https://example.com)`
- **コードブロック**:
  ```js
  console.log("Hello, World!");
  ```

詳細は[Markdown ガイド](https://www.markdownguide.org/)を参照してください。

### Q. 投稿が公開されない

- ネットワーク接続を確認してください。
- 必要に応じてブラウザをリロードして再試行してください。
- 解決しない場合、[サポート](mailto:support@example.com)にご連絡ください。
